# Hooks / Router Lab

A small React + Vite study app for Week 11.

## Run it

```sh
npm install
npm run dev
```

Open the local Vite URL. The Hooks lab demonstrates `useRef`, `useMemo`, `useCallback`, `useContext`, and a `useDocumentTitle` custom hook. The Router section demonstrates route layouts, nested routes with `Outlet`, params with `useParams`, and navigation with `Link` and `useNavigate`.

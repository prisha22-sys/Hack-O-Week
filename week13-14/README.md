# State & Styling Lab

A React study app for Weeks 13-14.

## Run it

```sh
npm install
npm run dev
```

Topics covered:

- Context API for shared state
- Prop drilling vs Context
- Local state, lifted state, Context, and `useReducer`
- CSS Modules, Tailwind CSS, and styled-components

The styling section shows representative code for each approach. CSS Modules and Tailwind need their respective project setup; styled-components needs the `styled-components` package.
